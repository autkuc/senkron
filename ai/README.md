# Senkron AI Module (`ai/`)

All LLM logic, model integrations, prompt templates, and social media post generation pipelines.

## Structure
- **`providers/`**: Integrations with LLM providers (e.g. OpenAI, Anthropic, Gemini).
- **`prompts/`**: Prompt templates for post generation across platforms.
- **`pipelines/`**: Post generation and content transformation workflows.
